Human vs Trojan 是一款双人浏览器网络攻防对抗游戏。攻击方与防守方在同一张网络挷拓图上展开不对称的战术博弁。你的每一次决定，都可能改变节点的归属与战局走向。Human vs Trojan is a two-player browser strategy game. The attacker and defender face off on the same network topology, using asymmetric tactics to contest control of the system. Every decision can change the state of the network—and the direction of the match.
